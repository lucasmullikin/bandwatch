# workers/

Transcription runs as a **separate process from the receiver**, and usually on
a different machine. A receiver is a cheap always-on box; a GPU usually is not.
Both workers poll the station's `/api/pending`, transcribe, and POST the text
back to `/api/transcript`.

Point them at the station with `BANDWATCH_URL`, and give them the worker token.

| worker | engine | where it makes sense |
|---|---|---|
| `whisper_worker.py` | mlx-whisper (Apple Silicon GPU) | a Mac with a GPU worth using |
| `whisper_cpu.py` | whisper.cpp, CPU | the receiver itself, as overflow |

## Two tiers, and why the slow one does not race

Measured on the author's hardware: the GPU worker turns a clip around in about
**0.5 s**; the CPU worker takes **9.6–19.2 s** and produces materially worse
text. So the CPU worker only claims clips older than `BANDWATCH_CPU_MIN_AGE`
minutes. It is a backstop for a backlog, never a competitor — without that
rule the slow worker wins some races and the transcript you keep is the worse
one.

## The worker token

`/api/transcript` rewrites the copy of record for what a transmission said, and
a watchlist match on that text can raise an alert. So it is authenticated.

The token is generated by the station on first use, stored `0600`, and is
gitignored. Copy it to the worker host at
`~/.config/bandwatch-worker-token`, or set `BANDWATCH_WORKER_TOKEN_FILE`.
Never commit it, and note that the tests assert it stays out of git.

## The rule that outranks every optimisation

**The watchlist is never passed to whisper as an `initial_prompt`.** Priming
the model with a term makes it emit that term, and the hit is then manufactured
by the prompt rather than heard on the air. Transcribe clean; match afterwards.

## Optional GPU arbitration

If several processes on one machine contend for a single GPU, set
`BANDWATCH_WHISPER_ARBITER=1` and `BANDWATCH_ARBITER_CLIENT` to a module
exposing `lease()`. Off by default: most machines have no such rule, and a
worker blocking on an arbiter nobody runs transcribes nothing.
